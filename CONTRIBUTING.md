# Join in

This is a small hobby project. Useful contributions include another board's
dedicated button mapping, a better small-screen interaction, or a reproducible
Linux installation fix. Open an issue with your OS, display size, audio stack,
and a minimal description of what happened. Remove tokens, device identifiers,
personal chats and recordings first.

Keep the UI local, preserve the SDK's command account and credential isolation,
and do not turn on microphone recording without an active foreground key press.
Do not commit downloaded character assets, voice models or generated builds.

See [development](docs/development.md) for checks. A hardware claim needs a
test on that hardware; fake-VM tests alone do not establish device support.
